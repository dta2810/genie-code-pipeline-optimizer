Genie Code Pipeline Optimizer

Governed, equivalence-gated pipeline optimization on Databricks Genie Code.

Per-Step Equivalence

Every intermediate table is fingerprinted. The assertion: row counts + schema match exactly, with one exception allowed per phase (configurable). The claim must be falsifiable by a deterministic query.

Whole-Job Flow Equivalence

The optimized job is replayed on sandbox clones in the same execution order. The flow graph (task dependency order, skips, dynamic branches) is compared against the original. Identity of each task's output is certified.

Production Untouched

All writes (sandbox clones, v2 notebooks, audit tables, intermediate assets) happen in isolated catalogs/schemas. The job definition itself is repointed only after Gate 2 approval and only if all proofs pass.

Green ≠ Proof

A successful sandbox run proves the code is sound, but not that the logic is correct. Equivalence checks are the proof. The human gates ensure domain knowledge validates the plan and the outcome.
