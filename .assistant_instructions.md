# OPTIONAL — not deployed by default

The entry point is the **`@optimize-pipeline`** skill, which is fully self-contained (flow,
human gates, audit contract, guardrails). Invoke it on demand:

```
@optimize-pipeline optimicemos el pipeline <job_name>
```

**Do NOT deploy this file to the workspace** (`/Workspace/Users/<you>/.assistant_instructions.md`)
unless you want always-on enforcement — it is workspace-global and would override the project's
own instructions. Prefer invoking `@optimize-pipeline` so the optimizer only engages when you ask.

Deploy only the skills:

```bash
databricks workspace import-dir .assistant/skills "/Workspace/Users/<you>/.assistant/skills" --overwrite
```
